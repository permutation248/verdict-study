# Utility-library benchmark suite (≥20-function subset)

These are single-file C utility libraries drawn from the **SpecSyn** benchmark
corpus (arXiv 2604.21570, "SpecSyn: LLM-based Synthesis and Refinement of Formal
Specifications for Real-world Program Verification"), selected as the files with
roughly 20 or more function definitions — i.e. the ones that approach or exceed
x509 submodule-1 (20 functions) in size. SpecSyn's corpus in turn credits the
Preguss artifact for the repository collection.

Each file is the **unannotated `common/` version** from the SpecSyn artifact;
the artifact's `oracle/` directories hold the authors' manually-written,
WP-verified ACSL ground truth, which we do not use here — every tool generates
its own specifications, scored by one unified judge.

Benches in this suite:

`ccan-time`, `cgl`, `char-utils`, `hypatia`, `jc-voronoi`, `maratis-math`,
`punity`, `sokol-shape`, `stb-divide`, `student-enrollment`, `zpl-math`.

Per-bench characteristics (function count, call depth, lines) appear in the
RQ1 table (generated by `scripts/figures/gen_rq1.py`).

Structural contrast with the x509 modules: these files are wide and shallow
(many mutually-independent leaf functions, shallow call chains), while the x509
submodules form deep call chains. Function-pointer audit: no indirect calls
that affect verification; all parse clean in Frama-C.
